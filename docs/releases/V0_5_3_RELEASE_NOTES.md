# Kall v0.5.3

Kall v0.5.3 adds evidence-grounded resume-tailoring proposals and explicit side-by-side review.

## Included

- Versioned tailoring proposals and change records
- Deterministic fallback generation
- Verified-achievement-only evidence
- Unsupported-requirement reporting
- Immutable date, percentage, compensation, and metric checks
- Accept, edit, and reject decisions
- Audit records for proposal creation, review, and finalization
- Finalization blocked until every change is reviewed
- Ownership-protected API endpoints
- Side-by-side web review workspace

## Safety

Employers, titles, dates, and metrics are not generated or silently changed. Sensitive EEO, authorization, reference, and privacy-controlled data remain outside the resume-tailoring pipeline. Final document generation remains a separate explicit step.
