# Roadmap

See [`docs/prd/02-roadmap.md`](prd/02-roadmap.md) for the phased product roadmap (Alpha / MVP Integration / Private Beta / Post-MVP) and [`docs/CHANGELOG.md`](CHANGELOG.md) for what has actually shipped. Current version: `0.9.0`.

The next milestone is not another feature slice — it's closing the gaps identified in the 2026-08-21 handoff assessment that 0.9.0 didn't already close: real ATS submission transport (vs. recorded-but-not-transported attempts), real notification delivery (vs. print stubs), a production scheduler runner for opportunity discovery, a frontend test suite + committed web lockfile, and standing up the mobile/desktop app shells beyond their README boundaries. These are tracked as Linear issues in the Kall project.
